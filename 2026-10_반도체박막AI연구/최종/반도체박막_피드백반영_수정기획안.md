# 반도체 박막 두께 예측 AI: 피드백 반영 수정 기획안

> 2026-10-25 · 팀 회의용 제안 · 모델 실험 전
>
> **주제는 잡음 안정성 평가로 유지하고, 절대오차(MAE)·상대오차(MAPE)·두께 구간별 분석을 함께 수행한다. 학습 손실은 MAE로 유지한다.**

## 1. 프로젝트를 이렇게 정하자

**발표 제목:** 반도체 박막 두께 예측 AI의 잡음 안정성 평가

**연구 범위:** 추가 잡음에 따른 층별·두께 구간별 절대오차와 상대오차 분석

226개 반사율 값으로 네 층의 두께를 동시에 예측하는 MLP 신경망을 만든다. 동일한 평가 입력에 크기가 다른 가우시안 잡음을 추가하고, 두께 예측이 얼마나 부정확해지고 흔들리는지 확인한다.

기존 기획에서 바꾸는 부분은 **두께에 따른 상대오차 해석**이다. 전체 평균뿐 아니라 각 층의 얇은 구간·중간 구간·두꺼운 구간을 나누어 평가한다. 잡음 증강 학습은 기본 분석 완료 후 선택 확장으로 둔다.

| 구분 | 기존 초안 | 수정 제안 |
|---|---|---|
| 주제 | 잡음에 따른 두께 예측 안정성 | 유지. 층별·두께 구간별 평가 범위를 명시 |
| 학습 | MAE + Adam | 유지. 손실 변경과 잡음 효과를 한꺼번에 섞지 않음 |
| 평가 | MAE·ΔMAE·예측 변화량 | MAPE·ΔMAPE와 두께 구간 분석 추가 |
| 데이터 설명 | 반사율 채널과 4층 두께 | 합성 데이터·원본 잡음·각 층 두께 분포 추가 |
| 실험 조건 | 잡음 세기 등 미정 | 시작 파라미터와 반복 수 제안 |
| 개선 실험 | 잡음 증강 모델 비교 | 기준 평가 완료 후 동일 구조·동일 학습 상한으로 비교 |

이 문서의 파라미터는 실행할 수 있도록 구체화한 **제안값**이다. 팀이 합의한 설정을 기록한 뒤 구현하며, 아직 학습 결과를 의미하지 않는다.

## 2. 팀원 피드백에 대한 판단

“두께가 일정하지 않다면 MAPE 혹은 정규화 MAE가 좋겠다”는 의견은 **같은 절대오차도 얇은 박막에서 더 큰 비율을 차지한다**는 점을 반영한다. 이 관점은 평가에 추가할 가치가 있다. 다만 두께가 변한다는 사실만으로 MAE가 부적절해지는 것은 아니다.

### 실제 데이터는 어떤가

기존 원본 전수 분석에서 네 출력 모두 10, 20, …, 300의 30개 값을 가지며, 각 값은 각 층에서 27,000회씩 나타났다. 네 층의 평균은 모두 155이고 범위와 표준편차도 동일하다. 전체 30⁴ = 810,000개 조합이다.

즉, 각 층의 두께는 표본마다 달라지지만 **어느 한 층만 수치 스케일이 훨씬 큰 데이터는 아니다.** 같은 두께 단위로 평균 절대오차를 비교할 수 있다. 근거는 `작업파일/원본_전수분석.json`이다.

### MAE·MAPE·정규화 MAE의 차이

| 지표 | 묻는 내용 | 이 연구에서의 판단 |
|---|---|---|
| MAE | 평균적으로 두께 수치가 얼마나 틀렸는가 | 기본 정확도 지표로 유지 |
| MAPE | 정답 두께 대비 몇 % 틀렸는가 | 상대적 부담을 보여 주는 핵심 보조 지표로 추가 |
| 범위로 나눈 MAE | 정해진 전체 범위 대비 오차가 얼마인가 | 네 층 모두 같은 범위라 정보가 거의 추가되지 않음 |
| 평균·표준편차로 나눈 MAE | 출력 스케일을 맞추면 오차가 얼마인가 | 네 층의 분포가 같아 층별 스케일 불균형 해결 효과가 작음 |

예를 들어 실제 두께가 20과 200인 표본을 각각 5만큼 틀렸다면, 절대오차는 둘 다 5이지만 상대오차는 25%와 2.5%다. 이것은 지표를 설명하기 위한 계산 예이며 모델 결과가 아니다.

범위 정규화 MAE를 `MAE / (300−10)`으로 정의하면 네 층 모두 `MAE / 290`이다. 같은 상수로 나누므로 층별 순위와 얇은 표본에 대한 가중치는 바뀌지 않는다. 평균 155로 나누는 방식도 표본별 두께 차이를 반영하지 못한다.

**결정 제안:** 학습 손실 MAE 유지, 평가 MAE + MAPE 병기, 층별·두께 구간별 분해. MAPE를 학습 손실로 바꾸는 실험은 이번 기본 범위에 넣지 않는다.

### MAPE를 쓸 때의 조건

- 정답 두께는 최소 10이므로 현재 원본에는 분모가 0인 문제가 없다. 상대오차는 두께 정답으로 나눈다. 반사율로 나누지 않는다.
- MAPE는 작은 두께의 동일 절대오차에 더 큰 가중치를 준다. 두께 10과 300에서는 동일 절대오차의 상대 기여가 30배 다르다. 이를 지표의 특성으로 설명한다.
- 목표 두께를 0~1로 최소·최대 정규화한 값에서 MAPE를 계산하면 최솟값 10이 0이 된다. **평가는 반드시 원래 두께 값에서 계산한다.**
- scikit-learn의 MAPE 반환값은 비율이다. 발표에서 %로 쓰려면 100을 곱한다. 0.05는 5%다. [공식 API 문서](https://scikit-learn.org/stable/modules/generated/sklearn.metrics.mean_absolute_percentage_error.html)

## 3. 연구 질문과 해석 범위

| 질문 | 확인할 결과 |
|---|---|
| RQ1. 추가 잡음이 커지면 절대·상대 두께 오차와 예측 변화량은 어떻게 변하는가? | σ별 MAE·MAPE·예측 변화량 곡선 |
| RQ2. 층과 실제 두께 구간에 따라 잡음에 대한 취약성이 다른가? | 각 층을 자기 정답 두께로 구간화한 오차·오차 증가량 |
| RQ3. 선택 확장: 잡음 증강 학습이 정확도와 안정성의 균형을 개선하는가? | 기준 모델과 증강 모델의 동일 조건 비교 |

잡음이 커지면 평균 성능이 나빠질 것이라는 예상은 검증할 가설이다. 개별 표본이나 모든 수준에서 반드시 단조 증가한다고 가정하지 않는다.

얇은 구간의 MAPE가 높다는 사실만으로 잡음에 더 민감하다고 결론 내리지 않는다. 분모가 작아지는 효과가 있기 때문이다. **같은 구간에서 추가 잡음 전후의 ΔMAE·ΔMAPE·예측 변화량을 함께 비교한다.**

이 연구에서 ‘층별 민감도’는 해당 모델의 입력 잡음에 대한 예측 민감도다. 특정 재료의 고유한 물리 민감도나 실제 계측기의 오차 한계를 직접 규명한 결과로 확대하지 않는다.

공식 설명에 따르면 반사율은 광학 계산 후 약 1% 잡음을 추가한 **합성 데이터**다. S0는 ‘추가 잡음 없음’이며 원본 잡음까지 없는 조건을 뜻하지 않는다. [데이터 생성 공식 공지](https://dacon.io/competitions/official/235554/talkboard/400310)

원본 구조는 질화규소/이산화규소/질화규소/이산화규소/규소 기판이다. 공식 자료는 질화규소의 광학상수 출처를 SiN·SiON으로 안내하므로, 발표에서는 단순히 ‘질화규소(SiN)’로 적는 것을 권한다. 원자 조성이 정확히 화학양론적 Si₃N₄인지 별도로 검증한 것으로 쓰지 않는다.

채널은 우선 0~225의 226개 채널 번호로 표시한다. 추가 공지의 0~255 표기 불일치가 해결되기 전에는 정확한 채널별 파장을 단정하지 않는다. 두께 물리 단위도 확인 전까지 ‘원본 두께 단위’로 표기한다.

## 5. 모델과 학습 시작 설정

이번 연구는 모델 종류 경쟁보다 평가 설계에 집중한다. MLP 구조 한 종류를 고정하고, 아래 값으로 예비 실행 후 검증 자료에서만 조정한다.

| 항목 | 시작 제안값 |
|---|---|
| 구현 | Python + PyTorch, 지표 검산에 NumPy/scikit-learn |
| 구조 | 226 입력, 160 뉴런 은닉층 3개, 4 출력 |
| 활성화 | 은닉층 ReLU, 출력층 선형 |
| 학습 손실 | 4개 출력에 동일 가중치의 MAE |
| 최적화 | Adam, 학습률 0.001 |
| 배치 | 1,024. 메모리 부족 시 예비 실행에서 조정 후 고정 |
| 최대 학습 | 100 epoch |
| 조기 종료 | 검증 MAE가 10 epoch 연속 개선되지 않으면 종료, 최저 검증 MAE 체크포인트 사용 |
| 시작 구성 | Dropout·BatchNorm·학습률 스케줄러 없이 시작 |
| 학습 난수 | 0, 1, 2의 3개 |
| 비교 기준 | 학습 자료의 층별 중앙값만 출력하는 단순 기준 모델도 함께 평가 |

최초에는 학습 분할의 일부로 3~5 epoch만 예비 실행해 입출력, 손실 감소, 소요시간과 메모리를 확인한다. 최종 성능은 전체 학습 분할로 학습한 모델에서 보고한다. 본 문서 작성 단계에서는 이 실행을 수행하지 않았다.

중앙값 모델은 정확도를 비교할 기준이면서, 입력이 달라도 출력이 변하지 않는 모델이 안정성 수치만으로는 좋아 보일 수 있음을 확인하는 대조군이다.

## 6. 잡음 실험 조건

원래 반사율 스케일에서 `x_noisy = x + σz`, `z ~ N(0, I)`로 추가 잡음을 만든다. 채널별 독립 정규 잡음은 이번 연구의 단순화된 가정이다.

**처리 순서:** 원본 입력 읽기 → 원본 스케일에서 잡음 추가 → 학습 자료로 구한 고정 표준화 적용 → 모델 예측. 표준화 후 모든 채널에 같은 σ를 넣는 다른 실험과 혼동하지 않는다.

| 조건 | 추가 잡음 표준편차 σ | 반복 |
|---|---:|---:|
| S0 | 0 | 잡음 생성 없음 |
| S1 | 0.0025 | 10회 |
| S2 | 0.005 | 10회 |
| S3 | 0.01 | 10회 |
| S4 | 0.02 | 10회 |

σ=0.01은 반사율의 절대 수치에서 표준편차 0.01이다. 각 반사율의 1%를 곱하는 상대 잡음과 다르며, 원본 생성 때의 ‘약 1%’와 같은 정의라는 의미도 아니다.

잡음 반복 난수는 100~109로 제안한다. 각 반복의 동일한 z를 σ에 따라 배율만 바꾸어 사용하고, 비교 모델에도 같은 표본·같은 잡음을 적용한다. 난수 생성기와 배치 순서까지 기록한다. 원본 입력에 잡음을 누적해서 더하지 않는다.

학습 난수 3개당 S0 1회와 S1~S4 각 10회를 평가하면 **모델 예측 평가 묶음은 123회**다. 123개 모델을 학습하는 것은 아니다. 기본 학습 모델은 3개다. S0 예측을 저장하고 배치 단위로 잡음을 생성하면 평가 메모리를 줄일 수 있다.

## 7. 평가 지표와 두께 구간

N은 평가 표본 수, l은 1~4층, y는 정답 두께, f는 학습 모델이다. 모든 오차 지표는 작을수록 좋지만 정확도와 일관성을 따로 해석한다.

| 지표 | 정의 | 용도 |
|---|---|---|
| MAE_l(σ) | `mean_i abs(f_l(x_i+σz_i)−y_il)` | 층별 절대오차. 전체는 4층 동일 가중 평균 |
| MAPE_l(σ) | `100 × mean_i [abs(f_l(x_i+σz_i)−y_il)/y_il]` | 층별 상대오차(%). 전체는 4층 동일 가중 평균 |
| ΔMAE | `MAE(σ)−MAE(0)` | 추가 잡음으로 증가한 절대오차 |
| ΔMAPE | `MAPE(σ)−MAPE(0)` | 추가 잡음으로 증가한 상대오차. 단위는 %p |
| 예측 변화량 D_l | `mean_i abs(f_l(x_i+σz_i)−f_l(x_i))` | 정답과 별개로 원본 예측에서 얼마나 변했는지 |
| 큰 오차 P95 | 표본마다 4층 절대오차를 평균한 후 그 값의 95백분위 | 평균이 감추는 일부 큰 오차 확인 |

MAPE는 ‘절대오차 평균 / 두께 평균’과 다르다. 반드시 표본별로 나눈 후 평균한다. ΔMAPE가 5%에서 7%로 변하면 +2%p다. +2% 또는 +40%라고 혼용하지 않는다.

### 두께 구간은 해당 층의 정답으로 분류

| 구간 이름 | 정답 두께 값 | 원본 전체에서 층별 포함 값 |
|---|---|---|
| 얇은 구간 | 10~100 | 10개 수준 |
| 중간 구간 | 110~200 | 10개 수준 |
| 두꺼운 구간 | 210~300 | 10개 수준 |

이는 원본 범위를 3등분한 분석용 이름이며 산업상 박막 분류 기준이 아니다. 최종 평가 분할의 실제 구간별 표본 수를 표에 함께 적는다.

Layer 1을 평가할 때는 Layer 1 정답으로, Layer 2를 평가할 때는 Layer 2 정답으로 나눈다. 한 행이 모든 층에서 동일 구간일 필요는 없다. 이 조건부 분석은 다른 층들의 두께가 함께 달라지는 데이터에서 얻는 모델 성능 분석이다.

기본 보고는 전체·4층의 σ별 MAE/MAPE다. 구간 분석은 S0와 S3(σ=0.01)를 먼저 비교하고, S4를 스트레스 조건으로 보완한다. 모든 σ의 수치는 보관하되 발표 그래프를 과도하게 늘리지 않는다.

## 8. 반복 결과와 성공 기준

각 학습 난수에서 잡음 10회 결과의 평균·변동을 계산한다. 팀에 제시하는 주요 비교는 **학습 난수 3개의 평균과 표준편차**다. 잡음 반복과 학습 난수의 변동을 구분해 기록한다.

같은 평가 박막에 잡음을 10번 더했다고 독립적인 박막 표본 수가 10배가 된 것으로 처리하지 않는다. 이번 소규모 연구에서는 유의확률 중심의 순위 경쟁보다 효과 크기와 난수별 일관성을 제시한다. 차이가 작거나 난수별 방향이 다르면 ‘개선이 불확실하다’고 보고한다.

**기본 연구의 완료 기준:** 단순 중앙값 기준과 비교한 모델 정확도, σ별 MAE·MAPE·예측 변화량, 층별·두께 구간별 결과를 재현 가능하게 제시하는 것이다. 근거 없이 ‘MAE 몇 이하’ 같은 산업 합격선을 설정하지 않는다. 예비 실행에서 모델이 제대로 학습되지 않으면 원인 해결이 먼저다.

## 11. 남겨야 할 결과와 발표 그림

최소 결과표는 `모델, 학습 난수, σ, 잡음 반복, 층, 두께 구간, 표본 수, MAE, MAPE(%), D, P95`를 추적할 수 있어야 한다. Δ지표는 같은 모델·층·구간의 S0와 대응시킨다. 예측값·정답·행 인덱스도 저장해 계산을 검산한다.

발표에 필요한 그림은 다음으로 제한한다. 결과가 없는 지금은 예시 곡선을 실제 결과처럼 채우지 않는다.

1. 대표 스펙트럼의 원본과 S3 추가 잡음 비교. 입력 잡음이 무엇인지 설명한다.
2. σ별 전체 MAE와 MAPE를 별도 축의 나란한 그래프로 표시한다.
3. 4층의 ΔMAE와 ΔMAPE를 비교한다. 층별 순위가 지표에 따라 달라지는지 확인한다.
4. S0·S3의 층별·두께 구간별 표 또는 열지도. 얇은 구간의 높은 MAPE와 실제 잡음 증가분을 구분한다.
5. 선택 확장 결과가 있으면 B0/B1의 S0·S3 비교를 추가한다.

실행 시 분할 난수, 라이브러리 버전, 체크포인트 선택 epoch, 표준화 통계, 잡음 생성 규칙을 설정 파일과 함께 남긴다. 실행 스크립트·명령·결과 폴더는 구현 단계에서 정하며 이 문서는 실행 완료 보고서가 아니다.
