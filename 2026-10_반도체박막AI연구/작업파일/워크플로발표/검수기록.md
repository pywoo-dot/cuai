# 워크플로 중심 주제발표 검수

- 날짜: 2026-10-26
- 최종 파일: 최종/CUAI_반도체박막_주제발표.pptx
- 사용자 방향: 주제발표 6장 유지, 목록 위주 구성 개선, 데이콘 이미지·피규어 포함, 프로젝트 워크플로 중심 설명.
- 표지: DACON 공식 대회 배너 원본 이미지를 임베드.
- 데이터: dodo의 공개 반사율 그림과 편집 가능한 적층 구조 표로 입력·출력을 설명.
- 워크플로: 데이터 준비, 기준 MLP 학습, 추가 잡음 주입, 안정성 비교를 편집 가능한 연결 도식으로 표현.
- 평가 계획: 동일 데이터·정답·학습 모델에서 원본과 추가 잡음 경로를 나란히 비교.
- 목표: 기본 분석과 조건부 잡음 증강 모델 비교를 도식화.
- 모델 학습·성능 시험은 미실행이며 그림을 팀 결과로 표시하지 않음.
- 새 이미지 2개는 바이트로 PPTX에 삽입. 최종 재가져오기 렌더에서 표시 확인.
- 마지막 최종 파일 6장을 모두 개별 이미지로 확인. 글자·이미지 잘림, 도식 연결 방향, 표의 기판 줄바꿈 확인·수정.
- 구조·글꼴·네이티브 표·재가져오기 검증 통과: 이미지포함검증.json.
- 전달 파일은 검수 완료 파일과 SHA256이 같음을 확인.
- 이전 목록형 6장판은 작업파일/이전판에 보존. 제공된 원본과 레퍼런스는 변경하지 않음.
