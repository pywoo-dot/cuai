# Claude 이어하기 안내 (2026-11-10 기준): CUAI 반도체 박막 MLP 프로젝트

이 문서는 다른 컴퓨터에서 Claude와 작업을 이어가기 위한 안내다. 2026-11-09 판 안내(`Claude_이어하기_안내.md`)보다 이 문서가 최신이다.

## 프로젝트와 팀 결정

- 연구 주제: 반사율 스펙트럼(226개 채널)으로 4개 박막층 두께를 예측하는 모델이 **입력 잡음에 얼마나 안정적인가**. 기준 문서는 `최종/반도체박막_잡음안정성_팀공유.html`과 `최종/반도체박막_피드백반영_수정기획안.md`.
- 팀 전략 1: 팀원 각자 모델을 구현해 2026-11-10(화) 회의에서 비교한 뒤 후속 실험을 정한다. 영우는 MLP 담당.
- 사용자가 MAPE와 두께 구간 분석(10~100 / 110~200 / 210~300)을 정식 지표로 넣기로 결정했다.

## 사용자 수준과 안내 방식

- Python 기초, AI 입문 단계. 단계별로 진행하고 새 함수·개념은 쉬운 말과 비유로 설명한다.
- **모든 답변은 한국어로** 한다.
- Claude가 코드 작성과 실행까지 맡는다. 실행 결과는 표로 정리해 보여준다.

## 지켜야 할 원칙

1. 최종평가(test) 분할은 팀이 모델·지표를 확정하기 전까지 사용하지 않는다. 설정 선택은 검증(val) 분할로만 한다.
2. 원본 데이터는 수정하지 않는다.
3. 기존 결과 파일은 지우지 않고, 새 실험은 다른 이름으로 저장한다.

### 새 컴퓨터에서 맨 처음 할 일

GitHub 저장소에는 크기 제한 때문에 원본 데이터(`작업파일/원본데이터/`, 약 2GB)와 `캐시/`(약 700MB)를 올리지 않았다.

1. 저장소 받기: `git clone https://github.com/pywoo-dot/cuai.git`
2. 원본 데이터 받기: `최종/반도체박막_원본데이터_확보안내.md`의 공식 링크에서 ZIP을 내려받아, `train.csv`, `test.csv`, `sample_submission.csv`를 `작업파일/원본데이터/`에 넣는다. `train.csv`는 1,964,116,076 bytes, 810,000행이어야 한다.
3. 캐시 다시 만들기: `작업파일`에서 `04_공통분할_만들기.py`를 한 번 실행하면 `캐시/X_all.npy`, `y_all.npy`가 만들어진다. 같은 seed라 저장소의 `공통분할/` 파일과 똑같은 분할이 나온다(최종평가 행 앞 5개 = [2, 4, 49, 67, 74]로 확인).
4. 학습된 모델(`작업파일/결과/*.pt`)은 저장소에 있으므로 다시 학습하지 않아도 `06_잡음평가.py`를 바로 실행할 수 있다.
- 다른 컴퓨터의 Python 경로가 다르면 `C:\anaconda\python.exe` 부분만 바꾼다.

## 코드

| 파일 | 내용 |
|---|---|
| `01~03_*.py` | 사용자가 처음 만든 연습 코드. 02의 표집 방식에 편향이 있어 쓰지 않지만 보존한다. |
| `04_공통분할_만들기.py` | 전체 81만 행을 seed 2026으로 섞어 학습 648,000 / 검증 81,000 / 최종평가 81,000. 캐시와 `공통분할/` 생성 |
| `05_모델학습.py` | `python 05_모델학습.py [seed] [뉴런수]`. 정답 표준화, 최대 300 epoch, 조기 종료 20, ReduceLROnPlateau(0.5, 5). 매 epoch `_last.pt`에 상태를 저장해 꺼져도 같은 명령으로 이어서 학습 |
| `06_잡음평가.py` | `python 06_잡음평가.py [val\|test] [모델이름표]`. S0~S4(σ 0/0.0025/0.005/0.01/0.02), 잡음 seed 100~109, 지표 MAE·MAPE·ΔMAE·D·P95, 층별·두께 구간별 |

모델 이름표: `_yscaled_lrs` = 160 뉴런 기준 모델, `_yscaled_lrs_h512` = 512 뉴런 모델.

## 지금까지의 결과 (모두 검증 분할)

| 단계 | 검증 MAE |
|---|---:|
| 중간값만 찍기 | 75.31 |
| 1. 기본 학습 (160 뉴런, 100 epoch, seed 0) | 17.91 |
| 2. 정답 표준화 (seed 3개) | 10.79 ± 0.49 |
| 3. 300 epoch + 학습률 스케줄러 = **현재 확정 기준 모델** | 8.87 ± 0.91 |
| 4. 뉴런 512 | 2.75 ± 0.04 |

잡음 평가 (S4, σ = 0.02): 160 모델 MAE 10.37, ΔMAE 1.50, D 5.39 / 512 모델 MAE 3.78, ΔMAE 1.03, D 2.61.
- 512 모델은 절대값으로는 더 안정적이지만, S0 대비 MAE 증가 비율은 17% → 37%로 커졌다.
- 잡음에 가장 약한 층은 2층, 다음이 3층. 얇은 구간(10~100)의 MAPE가 가장 크다.
- 자세한 수치와 과정은 프로젝트 `README.md` 하단과 `최종/MLP_최적화_정리.html`에 있다.

## 회의에서 정할 것 (결과를 사용자에게 먼저 물어볼 것)

1. 기준 모델을 512 뉴런으로 바꿀지 (발표 자료 구조는 226-160×3-4)
2. 안정성을 절대값(ΔMAE, D)으로 볼지 비율로 볼지
3. 팀원 모델과 비교할 지표 확정 → 확정 후 `06_잡음평가.py test`로 최종평가 분할 정식 결과
