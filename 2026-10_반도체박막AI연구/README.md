## 요약
원본 학습 810,000행·시험 10,000행을 읽고 구조와 수치 특성을 확인했다.
학습은 4개 층별 두께 30개 값의 전체 조합이며, 226개 광학 반사율에서 4개 두께를 추정한다.
공식 추가 공지에서 광학 계산+약 1% 잡음인 합성 데이터, 파장 범위·광학상수 출처·입사조건을 확인했다.
파장 선택을 우선 연구로 추천하고, 잡음 강건성과 광학 모델 보정을 확장 후보로 정리했다.
결측·무한값은 없으며 음수 반사율은 정상 데이터로 보존한다.
원본은 수정하지 않았고 모델 훈련이나 성능 비교는 수행하지 않았다.

## 다시 확인할 것
공식 공지의 0~255와 원본 0~225 불일치, 채널별 정확한 파수 매핑, 두께 단위, 잡음 분포·크기 정의.
시험 두께 정답은 미제공이며 제출양식의 0은 정답이 아니다.
실측 데이터에 대한 일반화와 신규성은 별도 검증이 필요하다.

## 만든 방법
대회 공식 Google Drive ZIP을 내려받아 SHA256과 CSV 3개를 확인했다.
번들 Python의 pandas·NumPy로 전체 CSV를 50,000행 단위로 읽어 통계·두께 조합·정렬을 검증했다.
PCA는 고정 난수로 학습 표본 20,000개를 추출해 별도로 계산했다.
공식 자료·코드와 관련 1차 연구를 읽고 실험 제안과 관찰 결과를 구분했다.
