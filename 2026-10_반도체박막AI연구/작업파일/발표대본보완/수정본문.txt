P.1 연구 주제 소개

안녕하세요, Basic 1팀 발표를 맡은 추서연이라고 합니다.

이번에 저희가 진행할 프로젝트는 반도체 박막 두께 예측 AI의 잡음 안정성 평가입니다.

일반적으로 AI 모델을 평가할 때는 예측 정확도를 중요하게 보는데요, 저희는 여기서 한 가지 더 나아가, 입력 데이터에 오차가 발생하더라도 AI가 안정적으로 예측할 수 있을까? 라는 질문에서 출발했습니다.

오늘은 이를 확인하기 위해 어떤 데이터와 모델을 사용하고, 앞으로 어떤 방식으로 프로젝트를 진행할 것인지 설명드리도록 하겠습니다.

P.2 반사율 데이터와 예측 대상

먼저 프로젝트에 사용할 데이터입니다.

데이터는 데이콘의 ‘반도체 박막 두께 분석 경진대회’에서 제공한 자료를 사용할 예정입니다.

이번 프로젝트에서는 반사율 데이터를 이용해 반도체 박막의 두께를 예측하는 AI 모델을 다룰 예정입니다.

입력 데이터는 왼쪽 그래프와 같이 226개 채널의 반사율 값으로 구성되어 있습니다.

이 반사율 패턴을 분석해 오른쪽에 보이는 네 개 박막층의 두께를 각각 예측하는 것이 기본적인 문제입니다.

박막은 질화규소와 이산화규소가 번갈아 쌓여 있는 구조이며, 가장 아래 규소 기판은 예측 대상에서 제외됩니다.

저희가 사용할 데이터는 약 81만 개의 학습 표본으로 이루어져 있으며, 광학 계산을 통해 생성된 합성 데이터입니다. 이 데이터를 활용해 단순히 두께를 예측하는 것에서 그치지 않고, 반사율 데이터가 달라졌을 때 예측 결과가 얼마나 영향을 받는지 분석해 보고자 합니다.

P.3 프로젝트 진행 흐름

저희 프로젝트는 크게 네 단계로 진행할 계획입니다.

먼저 첫 번째는 데이터 준비 단계입니다.

반사율 데이터와 실제 두께 정답을 확인하고, 모델 학습을 위한 데이터와 성능 평가를 위한 데이터를 분리할 예정입니다.

두 번째는 기준 모델 학습입니다.

이번 프로젝트에서는 MLP라는 기본적인 신경망 모델을 사용할 계획입니다. 우선 추가 잡음을 넣기 전의 원본 데이터를 이용해 모델을 학습시키고, 기본적인 두께 예측 성능을 확인할 것입니다.

세 번째는 잡음 주입 단계입니다.

원본 반사율 데이터에 가우시안 노이즈라는 무작위 잡음을 추가해, 측정 과정에서 오차가 발생하는 상황을 모의할 예정입니다.

마지막은 예측 결과 비교입니다.

원본 데이터와 추가 잡음을 넣은 데이터의 예측 결과를 비교해, 전체적인 정확도 변화와 각 층별 예측 오차를 분석할 계획입니다.

현재는 연구 주제와 실험 계획을 수립한 단계이며, 실제 모델 학습과 성능 평가는 앞으로 진행할 예정입니다.

P.4 잡음 전후 비교 계획

이번 프로젝트에서 가장 핵심이 되는 실험인데요, 저희가 확인하고자 하는 질문은 같은 박막인데 반사율에 오차가 발생한다면, AI의 두께 예측은 얼마나 달라질까? 입니다.

이를 확인하기 위해 동일한 평가 데이터를 두 가지 조건에서 비교할 계획입니다.

먼저 위쪽 흐름에서는 원본 반사율 데이터를 학습된 MLP 모델에 입력해 두께를 예측합니다. 그리고 아래쪽 흐름에서는 같은 반사율 데이터에 가우시안 노이즈를 추가한 뒤, 동일한 모델에 입력합니다.

여기서 중요한 점은 추가 잡음 조건을 제외한 나머지 조건은 동일하게 유지한다는 것입니다.

같은 평가 표본을 사용하기 때문에 실제 두께 정답도 동일하고, 예측에 사용하는 모델 역시 동일합니다. 이렇게 하면 입력 데이터에 추가한 잡음이 예측 결과에 어떤 영향을 미치는지 비교할 수 있습니다.

구체적으로는 실제 정답과 비교했을 때 예측 오차가 얼마나 증가하는지, 그리고 잡음을 추가하기 전후로 예측값 자체가 얼마나 달라지는지를 확인할 것입니다.

정답 대비 예측 오차는 절대오차를 보는 MAE와 상대오차를 보는 MAPE로 함께 비교할 계획입니다. 같은 크기의 오차라도 박막 두께에 따라 차지하는 비율이 달라지기 때문입니다.

이를 통해 단순한 예측 정확도뿐만 아니라, 모델이 입력 데이터의 오차에 얼마나 안정적으로 대응하는지도 평가해볼 계획입니다.

P.5 층별 비교와 해석 방향

앞선 실험을 진행한 뒤에는 결과를 크게 두 가지 관점에서 분석할 계획입니다.

첫 번째는 전체 예측 정확도의 변화입니다.

잡음이 추가되었을 때 전체적인 예측 오차가 얼마나 증가하는지 확인해 모델의 안정성을 평가하려고 합니다.

두 번째는 층별 예측 결과의 차이입니다.

이번 데이터는 네 개 박막층의 두께를 각각 예측하기 때문에, 잡음의 영향이 모든 층에서 동일하게 나타나지는 않을 수 있다고 생각했습니다. 예를 들어, 어떤 층은 잡음이 추가되어도 예측값이 크게 달라지지 않는 반면, 다른 층은 예측 오차가 크게 증가할 수도 있습니다.

이러한 차이를 비교해 어떤 층이 잡음에 더 민감한지, 그리고 어떤 조건에서 예측이 불안정해지는지 확인해 보고자 합니다.

추가로 시간적 여유가 있다면 잡음이 포함된 데이터를 학습에 활용하는 방법도 적용해, 잡음 증강 학습이 모델의 안정성을 개선할 수 있는지 비교할 계획입니다.

P.6 마무리

정리하자면, 이번 프로젝트에서는 반도체 박막의 두께를 예측하는 AI 모델을 구현하고, 입력 데이터에 잡음이 발생했을 때 예측 정확도와 안정성이 어떻게 달라지는지 분석하여 모델의 오차에 대한 견고성을 평가하고자 합니다.

이상으로 발표 마치겠습니다. 감사합니다.
