# 공통 데이터 분할 사용법 (팀 모델 비교용)

모두 같은 행으로 학습·검증·평가해야 모델끼리 공정하게 비교할 수 있습니다.

## 분할 규칙

- 대상: DACON `train.csv` 전체 810,000행 (헤더 제외, 첫 데이터 행 = 0번)
- 방법: `numpy.random.default_rng(2026).permutation(810000)` 결과를 앞에서부터 잘라 사용
- 학습 648,000 / 검증 81,000 / 최종평가 81,000
- 최종평가(test) 행은 모델·설정 선택에 쓰지 않고, 마지막 성능 보고에만 사용
- 확인용: 최종평가 행 번호 앞 5개는 `[2, 4, 49, 67, 74]`

## 파일

| 파일 | 내용 |
|---|---|
| `split_labels.csv` | `row`, `split` 두 열. 각 행이 `train`/`val`/`test` 중 어디인지 |
| `split_indices.npz` | `train_idx`, `val_idx`, `test_idx` 배열 (NumPy) |
| `input_scaler_train_only.npz` | 학습 분할로만 계산한 226개 채널의 `mean`, `std` (필요한 모델만 사용) |

## pandas 예시

```python
import pandas as pd

data = pd.read_csv("train.csv")
split = pd.read_csv("split_labels.csv")["split"].to_numpy()

train = data[split == "train"]
val = data[split == "val"]
test = data[split == "test"]
```

## 평가 지표 (기획안 기준)

- 두께는 원래 단위 그대로 예측·평가 (정규화했다면 되돌린 뒤 계산)
- MAE: 4개 층 평균 + 층별
- MAPE(%): 표본마다 `|예측-정답|/정답`을 구한 뒤 평균하고 100을 곱함
