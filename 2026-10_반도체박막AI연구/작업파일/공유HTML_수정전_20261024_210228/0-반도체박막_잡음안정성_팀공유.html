03

실험은 어떻게 진행하나요?

  1. 기준 모델 학습
    입력 226개 → 은닉층 160개 뉴런 × 3층 → 출력 두께 4개인 MLP를 사용합니다. MAE 손실과 Adam으로 시작하고, 학습 횟수·조기 종료 기준은 예비 실험에서 정한 뒤 고정합니다.

  2. 원본 기준 오차 측정
    추가 잡음이 없는 원본 평가 입력에서 전체·층별 두께 오차를 측정합니다. 이 값이 이후 비교의 기준입니다.

  3. 반사율에만 추가 잡음 적용
    같은 평가 표본에 크기가 다른 잡음을 더합니다. 네 층의 두께 정답은 바꾸지 않습니다.

  4. 반복 평가와 층별 비교
    추가 잡음 난수 10회, 학습 초기화 난수 3개로 평가합니다. 비교할 모델에는 동일한 평가 표본과 잡음 실현값을 사용합니다.

x추가 잡음 = x원본 + ε   /   ε ~ N(0, σ²)

각 채널에 독립적인 평균 0의 정규 잡음을 더하는 단순화된 실험 가정입니다. σ는 정규화 전 반사율 값의 절대 스케일에서 정의합니다.

추가 잡음 조건 설정안
조건표준편차 σ해석잡음 반복
S00추가 잡음 없는 원본 기준반복 생성 없음
S10.0025약한 추가 잡음10회
S20.005중간 추가 잡음10회
S30.01큰 추가 잡음10회
S40.02높은 스트레스 조건10회

σ = 0.01은 반사율 값 기준 표준편차 0.01이며, 각 관측값에 상대적으로 1%를 곱하는 설정이 아닙니다. 공식 데이터의 ‘약 1%’ 잡음과 동일한 분포·정의라는 뜻도 아닙니다.

기본 평가 이후 · 선택 확장

잡음 증강 학습으로 개선할 수 있을까요?

동일 구조의 모델을 학습할 때도 잡음을 추가해 비교합니다. 첫 후보는 σ = 0.005이며, 조정은 검증 자료에서만 합니다. 원본 학습 모델과 학습예산을 맞추고, 잡음 조건의 개선과 원본 입력 정확도의 손실을 함께 확인합니다.

04

무엇으로 안정성을 판단하나요?

정확도

두께를 잘 맞추는가?

전체·층별 MAE를 계산합니다. 추가 잡음 조건의 MAE에서 S0의 MAE를 뺀 오차 증가량도 제시합니다.

예측 일관성

얼마나 흔들리는가?

같은 모델에서 원본과 추가 잡음 입력의 예측 두께 차이의 절댓값을 표본·층 전체에 걸쳐 평균합니다.

큰 오차

일부에서 크게 실패하는가?

표본마다 네 층의 절대오차를 평균하고, 그 값의 95백분위를 비교합니다.

흔들림이 작다고 정확한 모델은 아닙니다. 항상 같은 두께를 출력하는 모델도 일관성은 높을 수 있습니다. 정확도와 예측 변화량을 반드시 함께 봅니다.

학습 난수별 결과와 평균·표준편차를 함께 제시합니다. 같은 표본에 잡음을 반복한 결과를 독립적인 새 박막 표본 수가 늘어난 것으로 해석하지 않습니다.

  • 잡음 증강 학습은 기본 평가 후 추가할 것인가?
완성할 결과물
  • 4층 구조와 두께 추정 흐름 설명
  • 잡음 크기 대 전체·층별 MAE 그래프
  • 예측 변화량과 95백분위 오차 그래프
  • 난수·분할·학습 조건이 기록된 결과표
  • 배경 → 방법 → 결과 → 해석 → 한계 발표
실험 전에 꼭 지킬 조건과 해석의 한계
  • 원본의 음수 반사율은 정상 데이터입니다. 기본 실험에서 삭제·절댓값 변환·0으로 자르기를 하지 않습니다. 추가 잡음 적용 후에도 기본 비교에서는 0~1로 자르지 않습니다.
  • 정규화 통계는 학습 분할에서만 구합니다. 최종 평가 결과를 보고 모델 설정을 다시 조정하지 않습니다.
  • 학습 두께는 10~300의 10 간격 격자입니다. 이번 분할은 그 범위 안의 성능을 평가합니다.
  • 반사율만 사용하며 투과율·공정 조건·불량 라벨은 없습니다. 실제 공장 적용이나 허용오차를 입증한 것으로 해석하지 않습니다.
  • 공식 공지의 채널 표기 0~255와 실제 CSV 0~225가 다릅니다. 채널별 파장 매핑과 두께 단위는 추가 확인합니다. 확인 전 두께 오차에 nm 단위를 붙이지 않습니다.
  • 본 문서는 기획안입니다. 아직 학습 결과·오차 수치·안정성 개선 결과는 없습니다.

공유할 때 사용할 소개 문장

이 연구는 반사율 스펙트럼에서 네 개 박막층의 두께를 추정하는 AI 모델이 입력 오차에 얼마나 민감한지 평가한다. 기존 합성 데이터에 크기가 다른 추가 잡음을 넣고, 두께 예측 오차와 동일 박막의 예측 변화량을 측정한다. 층별 민감도와 일부 표본의 큰 오차를 함께 확인하고, 필요하면 잡음 증강 학습으로 안정성을 개선할 수 있는지 비교한다.
