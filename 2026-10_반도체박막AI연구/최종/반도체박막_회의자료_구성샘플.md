# 반도체 박막 AI 팀 연구 — 회의자료 구성 샘플

> 현재 단계: 공개 자료 조사 완료, 상세 회의자료 구성 확인 및 원본 CSV 확보 대기. 2026-10-24 기준.
> 아래는 전체 보고서 제작 전 검토용 샘플이다. 원본 데이터를 직접 분석한 결과가 아니다.

## 확인된 문제

빛의 파장에 따른 반사율 226개를 입력받아 질화규소/이산화규소/질화규소/이산화규소 4층의 두께를 동시에 예측한다. 규소 기판 두께는 예측하지 않는다. 컬럼 0~225는 실제 파장값이 아니다.
[공식 데이터](https://dacon.io/competitions/official/235554/data)

| 파일 | 공식 표시 용량 | 공개 EDA의 행·열 | 용도 |
|---|---:|---:|---|
| train.csv | 1.82 GB | 810,000 × 230 | 두께 4개 + 반사율 226개 |
| test.csv | 23.0 MB | 10,000 × 227 | id + 반사율 226개 |
| sample_submission.csv | 214 KB | 원본 확인 전 | 제출 형식 |

행·열 수는 [참가자 공개 EDA의 실행 출력](https://dacon.io/competitions/official/235554/codeshare/1229)에서 확인했다. 원본 CSV 재검증은 아직 하지 않았다.
학습 타깃은 각 층마다 10~300, 간격 10인 30개 값이며 각 값 27,000회가 보고됐다. 단위는 공식 데이터 본문에서 확인되지 않아 nm로 단정하지 않는다.

평가는 MAE이며 당시 공개/비공개 평가는 시험 데이터의 각 50%였다. 공식 규칙은 외부 데이터를 금지한다.
[공식 규칙](https://dacon.io/competitions/official/235554/overview/rules)

## 주제 카드 샘플 — 일부 스펙트럼 채널로도 정확히 예측할 수 있는가?

- 연구 질문: 226개 중 16·32·64·128개 채널을 사용했을 때 정확도와 추론비용이 어떻게 달라지는가?
- 비교: 균등 선택, 무작위 선택 반복, 학습 데이터에서 선택한 채널, PCA 압축.
- 평가: 전체 및 층별 MAE, 95백분위 절대오차, 입력 개수, 동일 장비 추론시간.
- 필수 구분: PCA는 보통 226개 측정값 전체가 필요하므로 선택 채널만 측정하는 방식과 측정비용을 구분한다.
- 해석 한계: 실제 파장값이 없어 특정 nm 대역의 물리적 중요성을 주장할 수 없다.
- 위 내용은 연구 제안이다. 실험 성과나 신규성은 검증하지 않았다.

## 전체 자료 구성안

1. 대회·데이터 명세와 반도체·광학 배경
2. 공개 기준 모델·상위권 해법·기존 실험
3. 채널 축소 / 잡음 내성 / 불확실성 / 분포 변화 / 정방향 대리모델 / 경량화 주제 비교
4. 모든 팀의 공통 데이터 분할·지표·계산예산·역할·일정
5. 참고 논문과 코드, 미확인 항목 및 회의 의결 양식

공개 EDA의 0열 최솟값은 -0.014902였다. 물리적 범위라는 이유만으로 음수를 곧바로 삭제하거나 0으로 바꾸지 않는다.

## 바로 확인해야 하는 한계

- 원본 내려받기는 로그인 창으로 연결됐으며 아직 파일을 확보하지 못했다.
- 실제 파장, 광학상수, 입사각, 생성 방식, 두께 단위와 재이용 조건은 추가 확인이 필요하다.
- 학습 첫 행들은 두께 순서로 정렬돼 있다. 마지막 구간만 검증용으로 떼면 무작위 분할과 다른 문제를 평가할 수 있다.
- 연구 가설은 팀 회의에서 선택해야 하며, 원본 통계·실험 결과가 확보되기 전 성능 향상을 확정하지 않는다.
