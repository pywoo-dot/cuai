# CUAI 반도체 박막 AI 연구

반사율 스펙트럼(226개 채널)으로 4개 박막층의 두께를 예측하고, **입력에 잡음이 섞여도 예측이 안정적인지** 평가하는 CUAI 학회 팀 프로젝트입니다.

- 연구 기획: [팀 공유 기획](2026-10_반도체박막AI연구/최종/반도체박막_잡음안정성_팀공유.html), [수정 기획안](2026-10_반도체박막AI연구/최종/반도체박막_피드백반영_수정기획안.md)
- MLP 진행 기록(박영우): [최적화 정리](2026-10_반도체박막AI연구/최종/MLP_최적화_정리.html), [작업 기록](2026-10_반도체박막AI연구/README.md)

## 처음 시작하기

1. **저장소 받기**

   ```bash
   git clone https://github.com/pywoo-dot/cuai.git
   ```

2. **원본 데이터 받기.** 데이터는 용량(약 2GB) 때문에 저장소에 없습니다. [원본 데이터 확보 안내](2026-10_반도체박막AI연구/최종/반도체박막_원본데이터_확보안내.md)의 공식 링크에서 받아 `train.csv`, `test.csv`, `sample_submission.csv`를 아래 폴더에 넣습니다. 이 폴더는 Git에 올라가지 않습니다.

   ```
   2026-10_반도체박막AI연구/작업파일/원본데이터/
   ```

3. **필요한 패키지:** Python 3, numpy, pandas. MLP 코드를 돌리려면 PyTorch도 필요합니다.

4. **(선택) 캐시 만들기.** `작업파일`에서 `python 04_공통분할_만들기.py`를 한 번 실행하면 CSV를 빠르게 읽는 캐시가 생깁니다. 없어도 평가 도구는 CSV를 직접 읽습니다.

## 팀 공통 규칙

모델끼리 공정하게 비교하려고 아래를 모두 똑같이 맞춥니다.

| 항목 | 규칙 |
|---|---|
| 데이터 분할 | [`작업파일/공통분할/`](2026-10_반도체박막AI연구/작업파일/공통분할/사용법.md)의 학습 648,000 / 검증 81,000 / 최종평가 81,000 |
| 설정 고르기 | 검증(val) 분할로만 합니다 |
| 최종평가(test) 분할 | 팀이 모델과 지표를 확정할 때까지 **열지 않습니다** |
| 잡음 평가 | [`작업파일/공통평가.py`](2026-10_반도체박막AI연구/작업파일/공통평가.py) 사용. S0~S4(σ 0 / 0.0025 / 0.005 / 0.01 / 0.02), 잡음 seed 100~109 |
| 지표 | MAE, MAPE(%), ΔMAE, D(잡음 전후 예측 변화량), P95, 층별, 두께 구간별(10~100 / 110~200 / 210~300) |
| 학습 반복 | 가능하면 학습 seed 0·1·2로 세 번 학습해 평균 ± 표준편차 |
| 두께 단위 | 정답을 변환해 학습했다면 원래 두께로 되돌린 뒤 평가 |

## 내 모델 평가하기

어떤 모델이든 "원래 반사율 → 원래 단위 두께" 예측 함수만 만들면 됩니다. `작업파일` 폴더에서 실행합니다.

```python
from 공통평가 import evaluate

def my_predict(X_raw):      # X_raw: (N, 226) 원래 반사율 numpy 배열
    X = ...                 # 표준화 등 전처리는 여기서
    return model.predict(X) # (N, 4) 원래 두께 단위

evaluate(my_predict, model_name="이름_모델", split="val", train_seed=0)
```

결과는 `작업파일/결과/공통평가_val_이름_모델_seed0.csv`에 저장됩니다. 이 도구는 MLP 평가(`06_잡음평가.py`)와 같은 값을 내는 것을 확인했습니다.
