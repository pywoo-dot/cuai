# 반사율 스펙트럼 기반 다층 박막 두께 추정 모델의 잡음 안정성 평가

> AI 학회 팀 연구 기획안 · 2026-10-24 · 실험 전 초안
> 같은 박막의 반사율에 추가 잡음이 생겼을 때 AI의 두께 예측이 얼마나 흔들리는지 평가한다.

## 1. 연구 개요

박막 두께가 변하면 경계면에서 반사된 빛의 간섭이 달라져 반사율 스펙트럼이 변한다.
이를 역으로 이용하면 스펙트럼에서 두께를 추정할 수 있다.
본 연구는 226개 반사율 값에서 네 층의 두께를 추정하는 신경망을 만들고, 입력 잡음에 대한 안정성을 평가한다.

핵심 질문은 “동일한 두께를 가진 박막의 반사율이 조금 달라져도, 모델은 정확하고 일관된 두께를 예측하는가?”이다.
모델 구조는 한 종류로 고정해 잡음의 영향을 먼저 분리한다.
잡음 증강 학습을 통한 개선은 기본 평가가 끝난 뒤 선택적으로 확장한다.

## 2. 배경과 전공 연계

분석 대상은 질화규소/이산화규소/질화규소/이산화규소/규소 기판 구조다.
반사율에는 네 층의 두께와 물성에 의한 광학 응답이 함께 섞인다.
재료공학·차세대반도체 지식을 이용해 층별 오차를 해석하고, 광학 계측 오차가 두께 추정에 미치는 영향을 살펴본다.

자료는 광학 계산 결과에 약 1% 잡음을 추가해 만든 합성 데이터다.
따라서 잡음을 전혀 포함하지 않은 참값 스펙트럼을 갖고 하는 실험은 아니다.
‘원본 입력’은 이미 잡음이 포함된 입력이며, 이번 연구는 여기에 추가 오차를 주는 스트레스 시험이다.

## 3. 연구 질문과 가설

| 구분 | 내용 |
|---|---|
| RQ1 | 추가 잡음이 커질수록 평균 두께 오차와 예측 변화량이 얼마나 증가하는가? |
| RQ2 | 네 층 중 추가 잡음에 더 민감한 층이 있는가? |
| RQ3 · 선택 확장 | 학습 중 잡음을 추가하면 평가 시 성능 저하를 줄일 수 있는가? |
| 가설 1 | 추가 잡음이 큰 조건에서는 평균 오차와 예측 변화량이 대체로 커진다. |
| 가설 2 | 층별로 잡음에 대한 민감도가 다를 수 있다. |
| 가설 3 · 선택 확장 | 잡음 증강 학습은 큰 추가 잡음에서 유리할 수 있으나, 원본 입력 정확도에는 손실이 생길 수 있다. |

가설은 검증 대상이다. 어느 층이 더 취약한지, 오차가 단조 증가하는지, 증강이 개선하는지 미리 확정하지 않는다.

이 분할은 원본 격자 범위 안의 성능을 평가하며 범위 밖 두께나 실제 공장 데이터 일반화를 입증하지 않는다.

음수 반사율은 원본에 존재하는 정상 데이터이므로 기본 실험에서 삭제·절댓값 변환·0으로 자르기를 하지 않는다.
정규화가 필요하면 학습 분할에서만 통계를 구하고, 평가 지표는 원래 두께 수치로 복원해 계산한다.
두께의 물리 단위 확인 전에는 오차에 nm 단위를 붙이지 않는다.

## 5. 실험 구성

### 기본 실험: 모델 1종의 잡음 안정성 평가

MLP(다층 퍼셉트론) 하나로 진행한다.
시작 구조는 입력 226개, 은닉층 160개 뉴런 3층, 출력 4개로 한다.
MAE 손실과 Adam을 사용하고, 최대 학습 횟수와 조기 종료 기준은 예비 실험에서 정한 뒤 고정한다.
이는 대회 공식 기준 모델을 출발점으로 삼는 제안이며 아직 학습하지 않았다.
[공식 기준 모델](https://dacon.io/competitions/official/235554/codeshare/461)

1. 원본 학습 입력으로 기준 모델을 학습한다.
2. 원본 최종 평가 입력에서 기준 오차를 측정한다.
3. 동일한 평가 표본에 단계별 추가 잡음을 넣는다. 두께 정답은 그대로 유지한다.
4. 전체·층별 예측 오차와 예측 변화량을 비교한다.
5. 학습 초기화 난수 3개로 반복해 특정 학습 결과에만 의존하는지 확인한다.

### 추가 잡음 설정안

기본 가정은 각 채널에 독립적인 평균 0의 정규분포 잡음을 더하는 것이다.
x_noisy = x_original + epsilon, epsilon ~ N(0, sigma²).
sigma는 정규화 전 반사율 값의 절대 스케일에서 정의한다.

| 조건 | 추가 잡음 표준편차 sigma | 용도 |
|---|---:|---|
| S0 | 0 | 추가 잡음 없는 원본 기준 |
| S1 | 0.0025 | 약한 추가 잡음 |
| S2 | 0.005 | 중간 추가 잡음 |
| S3 | 0.01 | 큰 추가 잡음 |
| S4 | 0.02 | 높은 스트레스 조건 |

이 값들은 연구자가 정하는 실험 조건이다. 공식 데이터의 ‘약 1%’ 잡음과 동일한 분포·정의라는 뜻은 아니다.
예를 들어 sigma=0.01은 반사율 값 기준 0.01의 표준편차이며, 각 관측값에 상대적으로 1%를 곱하는 설정과 다르다.
이 가정은 단순화한 입력 교란이고 실제 장비의 모든 오차 특성을 대변하지 않는다.

S1~S4에서 잡음 난수를 10회 바꿔 평가한다. S0은 같은 입력이므로 반복 잡음을 만들지 않는다.
각 학습 모델·비교 방법에는 같은 평가 표본과 같은 잡음 실현값을 사용한다.
잡음을 넣은 뒤 기본 실험에서는 0~1로 자르지 않는다. 자르면 다른 전처리 효과가 함께 섞이기 때문이다.
원본 파일은 변경하지 않고 별도 실험 입력을 사용한다.

### 선택 확장: 잡음 증강 학습과 비교

기본 평가 후 필요하면 동일 구조의 모델에 학습 시 추가 잡음을 넣어 비교한다.
첫 후보는 학습 잡음 sigma=0.005로 두되, 값 선택이 필요하면 검증 자료만 사용한다.
그 외 모델 구조·데이터 분할·최대 학습예산은 맞춘다.

| 비교군 | 학습 입력 | 평가 입력 |
|---|---|---|
| A | 원본 | S0~S4 |
| B · 확장 | 원본 + 학습 시 추가 잡음 | A와 동일한 S0~S4 |

개선 여부는 추가 잡음 조건의 오차 감소와 S0의 정확도 손실을 함께 보고 판단한다.
재료·물리 모델 구현이나 여러 딥러닝 구조 비교는 이번 최소 범위에 포함하지 않는다.

## 6. 안정성의 평가 기준

### 정확도: 두께를 잘 맞추는가?

전체 MAE = 모든 평가 표본과 네 층에 대한 |예측 두께−정답 두께|의 평균.
층별 MAE도 각각 보고한다.
추가 잡음에 따른 성능 저하는 ΔMAE(sigma)=MAE(sigma)−MAE(0)로 측정한다.
작은 기준 MAE로 나눌 때 증가율이 과장될 수 있어 절대 증가량을 우선 제시한다.

### 일관성: 같은 박막의 예측이 얼마나 흔들리는가?

예측 변화량 D(sigma) = 모든 표본과 층에 대한 |f(x+epsilon)−f(x)|의 평균.
이는 동일 모델의 원본 입력 예측을 기준으로 계산한다.
잡음 반복 10회의 평균과 변동 범위도 표시한다.

정확도와 일관성은 다른 지표다.
항상 같은 두께를 출력하는 모델도 일관성은 높을 수 있으므로, 예측 변화량만으로 좋은 모델이라고 판단하지 않는다.

### 큰 실패: 일부 표본에서 오차가 매우 커지는가?

표본마다 네 층의 절대오차를 평균한 값을 구하고, 그 값의 95백분위를 보고한다.
평균 MAE가 작아도 일부 박막 조합에서 오차가 커지는지 확인한다.
필요하면 취약 표본의 두께 조합과 스펙트럼을 추가로 살펴보되 최종 평가 결과를 보고 모델을 재조정하지 않는다.

학습 난수 3회의 결과는 각각 공개하고 평균·표준편차를 요약한다.
같은 평가 표본에 반복 잡음을 준 결과를 독립적인 새 박막 표본이 늘어난 것으로 해석하지 않는다.
실용적인 허용 오차 기준은 단위·계측 목표가 확인된 후 정하며, 임의의 수치를 산업적 합격 기준으로 주장하지 않는다.

발표는 ① 배경·문제 정의 ② 데이터와 원리 ③ 모델·잡음 설정 ④ 평가 결과 ⑤ 층별 해석 ⑥ 한계·후속 연구 순서로 구성한다.
그래프는 실제 실험 후 작성하며 예상 성능 숫자는 기획안에 넣지 않는다.

## 9. 최소 범위와 연구의 한계

최소 완성 범위는 MLP 1종, 학습 난수 3개, 추가 잡음 5수준, 잡음 반복 10회, 정확도·변화량·큰 오차 분석이다.
부담이 크면 모델 1회 학습으로 코드·평가 절차를 먼저 확인하고, 최종 보고 전 3회 반복을 완료한다.
잡음 증강은 선택 확장으로 남긴다.

본 연구는 기존 방법의 잡음 민감도 실험이다. 새로운 알고리즘이라고 미리 주장하지 않는다.
실험 자체가 유효하더라도 실제 장비의 허용오차나 공정 적용 성능은 별도 실측 검증이 필요하다.
데이터 생성 방식·단순 잡음 가정·두께 격자·미확인 단위를 명시해 해석 범위를 제한한다.

기존 합성 데이터에 크기가 다른 추가 잡음을 넣고, 두께 예측 오차와 동일 박막의 예측 변화량을 측정한다.
특히 층별 민감도와 일부 표본의 큰 오차를 함께 확인하며, 필요하면 잡음 증강 학습으로 안정성을 개선할 수 있는지 비교한다.”
