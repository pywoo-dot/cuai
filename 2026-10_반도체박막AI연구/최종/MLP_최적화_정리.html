공통 데이터 분할 만들기

증상
기존 분할 코드(02_데이터분할.py)는 81만 개를 덩어리로 나눈 뒤, 덩어리마다 같은 위치만 뽑았습니다. 그 결과 4층 두께값별 표본 수가 2,419~2,943개로 고르지 않았습니다.
바꾼 것
전체를 한 번에 고르게 섞어 세 묶음으로 나눴습니다(04_공통분할_만들기.py). 팀원도 같은 행으로 비교할 수 있게 공통분할/ 폴더에 파일과 사용법을 두었습니다.
1

기본 학습

검증 MAE 17.91
설정
뉴런 160개 × 3층, 100 epoch, 정답 두께는 원래 숫자(10~300) 그대로
결과
중간값만 찍을 때(75.31)보다 훨씬 좋아져, 모델이 반사율에서 무언가를 배운다는 것은 확인했습니다. seed 0 하나만 학습했습니다.
증상
배우는 속도가 느렸습니다. 30 epoch에 23.60이었고, 100 epoch 마지막까지 계속 좋아지는 중이었습니다.
2

정답 표준화

17.91 → 10.79 ± 0.49
바꾼 것
모델이 맞힐 정답을 (두께 − 155.0) ÷ 86.5로 바꿨습니다. 10~300이던 두께가 약 −1.7~+1.7이 됩니다. 예측은 거꾸로 계산해 원래 두께로 되돌린 뒤 평가합니다.
결과
같은 100 epoch에서 seed 0·1·2가 11.36 / 10.51 / 10.50. 30 epoch 시점도 23.60 → 14.71로 빨라졌습니다.
모델은 처음에 0 근처 숫자만 내놓고, 한 번에 아주 작은 보폭으로만 움직입니다. 정답이 250이면 거기까지 걸어가는 데 학습 시간을 다 쓰지만, 1.1이면 금방 도착해 남은 시간에 세밀한 차이를 배웁니다.
3

더 오래 학습 + 학습률 스케줄러

10.79 → 8.87 ± 0.91
증상
100 epoch에서도 검증 MAE가 계속 내려가는 중이었습니다. 덜 배우고 멈춘 상태였습니다.
바꾼 것
최대 300 epoch, 20 epoch 동안 나아지지 않으면 조기 종료. 검증 MAE가 5 epoch 동안 정체되면 학습률을 절반으로 줄였습니다.
결과
seed 0·1·2가 9.90(215 epoch) / 8.54(258) / 8.17(294). 학습률이 1e-7 수준까지 줄어 끝까지 수렴했습니다. 이 모델을 기준 모델로 정했습니다.
남은 문제
학습 MAE(8.99)와 검증 MAE(9.90)가 거의 같았습니다. 연습문제조차 잘 못 푸는 상태, 즉 모델 용량이 부족하다는 신호입니다. seed마다 결과 차이도 컸습니다.
학습률은 보폭입니다. 처음엔 크게 움직여 빨리 다가가고, 더 나아지지 않으면 보폭을 줄여 정답 근처를 세밀하게 찾습니다.
4

뉴런 수 늘리기 (160 → 512)

8.87 → 2.75 ± 0.04
바꾼 것
은닉층 한 층의 뉴런을 160개에서 512개로 늘렸습니다. 모델이 조정하는 숫자(가중치)가 88,484개에서 643,588개로 약 7배가 됩니다. 나머지 설정은 3단계와 같습니다.
결과
seed 0·1·2가 2.71(214 epoch) / 2.80(212) / 2.74(208). 정확도가 3배 좋아졌고, seed 간 차이가 0.91에서 0.04로 줄어 학습할 때마다 거의 같은 결과가 나옵니다.
대가
epoch당 시간이 약 6~12초에서 약 40초로 늘었습니다(세 개 동시 실행 기준). 한 번 학습에 약 2시간 반이 걸렸습니다.
뉴런 하나는 반사율에서 특징 하나를 알아보는 작은 탐지기입니다. 탐지기가 많을수록 "2층이 120인지 130인지" 같은 미세한 차이까지 구분할 수 있습니다.
학습 MAE(1.56)와 검증 MAE(2.71)의 차이가 1.1 정도로 벌어지기 시작했습니다. 아직 검증 MAE가 좋아지고 있어 문제는 아니지만, 이보다 더 키우면 연습문제만 외우는 과적합이 생길 수 있습니다.

알게 된 것

  • 모델을 키우자 정확도와 안정성이 함께 좋아졌습니다. 가장 강한 잡음(S4)에서 흔들림 D가 5.39에서 2.61로 절반이 됐습니다. S4에서의 MAE 3.78도 기준 모델의 잡음 없는 MAE 8.87보다 낮습니다.
  • 비율로 보면 반대입니다. 잡음 없을 때보다 MAE가 늘어난 비율이 S4에서 17%(1.50 ÷ 8.87)에서 37%(1.03 ÷ 2.75)로 커졌습니다. 기본 오차가 작아져서 같은 잡음이 상대적으로 더 크게 보입니다.
  • 2층이 가장 잡음에 약하고, 그다음이 3층입니다. 두 모델 모두 같습니다. S4 흔들림 D(1·2·3·4층 순)는 160 모델 4.33 / 7.77 / 5.89 / 3.58, 512 모델 2.02 / 3.55 / 2.78 / 2.08입니다. 160 모델에서는 1층이 4층보다 약했지만, 512 모델에서는 둘이 거의 같아졌습니다.
  • 얇은 막(10~100)이 가장 어렵습니다. 512 모델에서도 얇은 구간 MAPE가 9.3~14.3%로, 두꺼운 구간(0.7~1.3%)보다 훨씬 큽니다. 두께가 작아 같은 오차도 %로는 크게 나오는 이유도 있습니다.

진행 중 생긴 문제

  • 512 뉴런 학습 세 개가 15:09에 동시에 중간 종료됐습니다(원인 미확인). 그때까지의 모델은 _h512_중단본 이름으로 보존했습니다.
  • 재발에 대비해 학습 코드에 이어하기 기능을 넣었습니다. 매 epoch 상태를 저장해 두고, 같은 명령을 다시 실행하면 멈춘 epoch부터 계속합니다. 그 뒤 세 seed를 처음부터 다시 학습했습니다.

회의에서 정할 것

  • 기준 모델을 512 뉴런으로 바꿀지. 발표 자료의 구조는 226-160×3-4입니다. 바꾸지 않더라도 "모델 크기와 잡음 안정성" 비교 결과로 쓸 수 있습니다.
  • 안정성을 절대값으로 볼지, 비율로 볼지. 절대값(ΔMAE, D)이면 512가 더 안정적이고, 비율이면 160이 더 안정적입니다.
  • 팀원 모델과 비교할 지표 확정. 확정되면 최종평가 분할로 한 번만 정식 결과를 냅니다.

용어

MAE
예측 두께와 정답의 차이를 평균낸 값. 단위는 두께 그대로이고, 낮을수록 좋습니다.
MAPE
틀린 정도를 정답 대비 %로 나타낸 값. 얇은 막일수록 크게 나옵니다.
ΔMAE
잡음을 넣었을 때 MAE가 늘어난 양 (잡음 MAE − 잡음 없는 MAE).
흔들림 D
잡음 전후로 예측이 바뀐 양의 평균. 정답과 상관없이 일관성만 봅니다.
P95
표본별 오차를 줄 세웠을 때 상위 5% 경계. 크게 틀리는 경우를 봅니다.
epoch
학습 데이터 648,000개를 한 바퀴 모두 보는 것.
seed
처음 가중치와 섞는 순서를 정하는 난수. 운이 아니라 실력인지 보려고 0·1·2 세 번 학습합니다.
학습률
가중치를 한 번 고칠 때의 보폭.
